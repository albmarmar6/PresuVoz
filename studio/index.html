Transcripción / Texto manual

Cómo usar este demostrador

1

Pulsa "Iniciar grabación" y habla

Di una descripción de obra real. Por ejemplo: el cliente, la calle, las partidas y los precios. No hace falta ningún formato especial.

2

Revisa la transcripción y ajusta si hace falta

El texto aparece en tiempo real. Puedes editar cualquier dato directamente en el cuadro de texto.

3

Pulsa "Generar presupuesto"

El motor calcula las partidas, aplica el IVA correcto y genera el documento formal con sello de empresa y lienzo de firma del cliente.

Nota sobre el producto final

En producción, el profesional no abre ningún navegador. Envía el audio directamente desde WhatsApp y el sistema responde en el mismo chat con el PDF y el enlace de firma. Este estudio solo sirve para demostrar la tecnología y validar el flujo.
